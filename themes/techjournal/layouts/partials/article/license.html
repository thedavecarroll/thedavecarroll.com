The source line is shown when params.article.license.source is set; it states the page's own URL as visible text, so a copy of the article carries it. The text comes from params.article.license.default; a page can override it with `license` in front matter, or hide the notice with `license: false`. The link uses the site-wide params.license.name and params.license.url. */ -}} {{- $cfg := site.Params.article.license -}} {{- if and $cfg.enabled (ne .Params.license false) }} {{- $text := .Params.license | default $cfg.default -}} {{- $lic := site.Params.license -}}

{{- end }}
